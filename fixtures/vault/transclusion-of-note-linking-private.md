# Transclusion of a note linking a private note

The confidentiality case that §3.7 step 4 exists for. A transcludes published
note B, and B links to unpublished note C. Inlining B's *raw source* would
carry C's title straight into A's published page without ever passing the drop
rule, because step 3 already ran over A and never sees material that arrives
by transclusion.

![[published-b]]

Composing from B's **staged output** means B's own staging already handled C.
