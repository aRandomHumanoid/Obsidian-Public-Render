# The original

"Make a copy" in the file explorer is one click and copies frontmatter with
it, producing two notes claiming one share_id. Validating uniqueness only when
a note is staged would let the duplicate sit undetected until someone stages
it — possibly months later, possibly overwriting the wrong page (§3.4).
